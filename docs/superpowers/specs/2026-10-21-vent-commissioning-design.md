Second distinct Android-only product slice under published-android-workflows design. Preserve original duct/room-air-change calculator expressions and source version/identity. Root owns all execution; actual RED before production.

`VentSide.SUPPLY/EXTRACT`; `VentRoom(id,name)`; `VentTerminal(id,roomID,name,side,targetM3H,measuredM3H)`; `VentVisit(id,recordedAt,rooms,terminals,note)` immutable full snapshot; `VentProject(id,name,rooms,terminals,visits)`; `VentCommissioningBook(schema=1,revision,projects)`. Unique canonical UUIDs within current archive; snapshot IDs intentionally refer to the historical same room/terminal. Valid finite target/measured flow0..100000m³/h, required trimmed names≤120, notes≤2000, canonical UTC Instant. Up to20projects/40rooms/80terminals/40visits per project, archive≤4MiB, no silent eviction. Old snapshots may retain removed current terminal/renamed room. Terminal room must belong to its current/snapshot project; no deleting a room while current terminals refer to it. Append visit only with actual terminals; never overwrite an old visit.

`VentCommissioningRules.addProject(book,id,name)`, `putRoom(book,projectID,room)`, `putTerminal(book,projectID,terminal)`, `removeRoom/book,projectID,roomID`, `removeTerminal(book,projectID,terminalID)`, `recordVisit(book,projectID,id,recordedAt,note)`, `totals(terminals,side)`, `report(book,projectID,english)`. All mutation returns copied book incrementing revision. `VentTotals` targetM3H/measuredM3H/deviationM3H/deviationPercent(nullable)/measuredLitresPerSecond/measuredCFM. Deviation is measured−target; percentage absent if target0. Supply and extract always independent; no silent netting. Existing exact conversions m³/h÷3.6 and m³/h×0.588577779. User-supplied targets, no automatic standards/certification claim. Per-room and whole-project separate side totals, explicit current terminal values and immutable before/after adjustment history in DE/EN share report.

`VentCommissioningCodec.encode/decode` strict whole JSON/exact required fields/schema/IDs/limits; `VentCommissioningFile(file,optionalwriter).load/save(book,expectedRevision)` same exact actual file preservation contract as Kälte. Separate `vent-commissioning-v1.json` package-local file, no Apple migration/reuse. Missing empty, corrupt/future/trailing preserve/block, exact committed retries, stale revision and failed temp replacement retain old bytes. No new runtime dependency.

Native UI after actual pure GREEN: named projects/rooms/terminals, supply/extract selection, raw-string target/measured input, room/project totals, explicit dated adjustment snapshot save, visit detail with its original names/facts and sharing. Stable IDs, blank-invalid Save disabled, error-safe durable writes before publish, rememberSaveable raw editor/selection, discard confirmation, safeDrawing/imePadding/wrapping/full-width controls.
