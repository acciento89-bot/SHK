# Kamilunavo SHK Suite

Gemeinsames Entwicklungs-Repository für die eigenständigen SHK-Apps von Kamilunavo.

## Apps

1. KälteCalc
2. LüftungsCalc
3. HeizkörperCalc
4. RohrCalc
5. AnlagenCheck

Jede App bleibt ein eigenständiges iOS-Produkt mit eigener Bundle-ID, eigenem App-Store-Eintrag und eigener Release-Version. Gemeinsame Fachlogik, UI-Bausteine, Tests und Release-Werkzeuge werden innerhalb dieses Repositories geteilt.

## Nicht Bestandteil dieses Repositories

AbgleichCalc wird nicht umgesetzt. Die hydraulischen Abgleich-/Volumenstrom-Funktionen werden bereits durch HydroCalc abgedeckt.
